# 关于本人后台与博客联动

- 后台 `/blog/about` 改为唯一资料编辑工作台，无列表、搜索、分页和新增资料按钮。
- 后台提供 7 个分区，覆盖页面状态、访问方式、独立头像、标签、介绍、追求、Hello 文案、技能图标、经历、人格、照片、座右铭、特长、游戏、番剧、兴趣偏好、自定义卡片、社交、打赏和正文。所有模块支持显示开关（顶部名片按字段展示），重复条目支持排序。
- 新接口：`GET/PUT /blog/admin/about`，权限分别为 `blog:about:list/update`；`GET /blog/public/about` 遵守草稿/定时发布/访问权限。沿用旧记录 ID 与媒体引用。
- 有多份历史记录时稳定选择最小 ID，不删除其他历史数据。旧通用新增接口拒绝创建第二份资料。首次单例保存把服务端兼容默认值写入原记录，显式空字符串/空数组不会回退默认内容。
- 博客使用独立 AboutPage、单一 about-page 容器、响应式卡片网格；不再嵌套通用列表半宽卡片。

## 实际验证

- 真实后台把主标题暂改为“关于我 · 联动验证”，保存成功；公开 API 同一 ID 返回更新内容，刷新博客显示同样标题；随后已通过后台恢复“关于我”并保存。
- 桌面检查：关于页使用完整内容宽度，两列卡片；后台直接显示分区表单。
- 390px 手机宽度：正文 scrollWidth=390，无横向溢出，卡片单列，头像和标签适配。
- 博客全套原有及更新测试 97 项通过，追加模块开关与重试用例后关于页 5 项通过；后端全套 72 项通过，追加 9 项受限图片检查后针对性 21 项通过；后台保存状态测试 2 项通过。
- 真实 API 集成验证 47 项通过，测试数据已清理。
- 独立代码审查发现并修复：受限图片字段漏检、关于页错误状态按钮未绑定重试。
- 博客/后台/后端构建及后台类型检查通过。原有构建提示：大体积 bundle、旧 npm 配置项、两个既有 UnoCSS 图标缺失。
