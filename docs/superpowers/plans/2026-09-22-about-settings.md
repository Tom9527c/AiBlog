# 关于本人单页配置 Implementation Plan

**Goal:** 后台直接编辑唯一关于页；博客所有个人展示数据由后台控制。
**Architecture:** 保留 blog_about 与媒体引用/访问权限体系。增加单例 GET/PUT 和公开 GET，以固定选择的现有记录保持兼容；表单按模块编辑 metadata，博客使用独立页面去掉列表布局。
**Tech Stack:** NestJS / TypeORM / Vue 3 / Naive UI / React / Vitest / Jest。
**Spec:** 用户已确认本会话四项设计，继续在当前目录实施（根目录无 Git 仓库）。

- [x] 后端：补充 metadata 字段/嵌套条目校验，旧资料在服务端归一化；单例读写保留原 ID、媒体引用与权限；公开读取遵循发布规则。
- [x] 后台：独立分区编辑页，直接加载/保存；基础资料、介绍、技能经历、生活偏好、卡片、社交打赏；图片上传、排序、撤销、未保存提醒。
- [x] 博客：独立 AboutPage，唯一 about-page 容器，完整数据驱动 AboutCards，空字段不恢复默认个人信息。
- [x] 验证：metadata 非法链接/结构拒绝；单例读写/发布权限；自定义与清空内容渲染；三端构建和浏览器检查。

验收行为：修改姓名、游戏 UID、技能图标与番剧封面后保存，公开接口与博客对应内容一致；清空内容后不再展示旧硬编码；后台无搜索/表格/分页/新增资料入口。
