# 即刻短文播报和卡片对齐验证

- 短文卡片删除分享按钮，只保留评论；底部日期、地点、心情、天气、来源与评论按钮统一24/32px垂直中心线，重置主题按钮内边距。
- 首页 ticker 请求 `accessMode=public`，后端在 SQL 层过滤公开、已发布、已到发布时间内容，前端再次过滤锁定项；每5秒随机切换，避免相邻重复，悬停/聚焦暂停。
- 正文转换规则：Markdown 图片、HTML img/video/audio 在原位置转为 `[图片]`/`[视频]`/`[音乐]`；独立附件按顺序追加，去重；无正文回退摘要/标题；不泄漏媒体 URL、HTML、脚本。
- 播报链接指向当前 `/essay/?id=...`，空数据回退公告。

验证：ticker 前端单测4项、短文卡片单测1项、首页测试3项通过；博客全量116项通过；后端短文专项15项、真实接口回归57项通过。桌面首页实测播报文本为 `123123123[视频][视频][图片]`，5秒后切换至另一条；手机390px短文页卡片宽358px、document.scrollWidth=390，分享按钮不存在。
