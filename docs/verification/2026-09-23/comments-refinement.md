# 评论样式与后台审核优化

- 前台评论移除 CommentJinBu 外部字体，继承博客字体；强调色、输入背景、边框、占位符和禁用按钮使用博客主题变量。
- 后台改为全宽紧凑表格，默认每页 20 条，可选择 10/20/50/100；保留状态/来源/关键字过滤、批量审核。
- 主评论可展开回复，按父评论在服务端分页，展开区显示全部审核状态，每页 10 条。主审核列表仍显示符合筛选的每条评论（包括子回复），避免漏审。详情移至抽屉。
- 列表及详情显示 IP、属地、系统、浏览器版本。新提交及管理员回复由服务端记录 rawIp，沿用可信代理解析；公开接口继续使用元数据白名单，历史缺失 IP 显示“未记录”。无需数据库结构迁移。
- 表情调查：CommentComposer 中固定 16 个 Unicode Emoji，未接入后台表情包管理。本次按确认范围不新增上传功能。
