# 首页文章卡片还原验收

本轮针对用户提供的两张文章卡片截图修复，以 `Tom9527c.github.io-main` 的实际 HTML、主题 CSS、Element UI CSS 和 `custom/css/aurora.css` 为基准。

## 已修复

- 移除写死的“原创”。公开文章接口返回全局最新发布标记，独立于置顶排序、筛选和分页；详情成功加载且允许阅读后保存本地已读状态。
- 恢复“发表于 / 更新于”的日期格式、图标和标签行。分类与标签使用现有表数据，由公开接口批量返回 id/title/slug，过滤未发布及未来发布的分类、标签。
- 恢复原站 18px 标题、状态行、文字间距、26px 分类角标、25px 卡片圆角、图片裁剪与悬停效果。
- 桌面卡片宽度 49%，封面 225px，信息区 174px；769–1200px 使用单列横向卡片，封面 200px、信息区垂直居中；768px 及以下使用单列纵向卡片，封面 200px。
- 修复英文与中文混排时字体回退差异。原站未设置 `--global-font`，本机 Chrome 实际使用 PingFang SC；卡片沿用原站默认回退，同时保留该变量的扩展能力。
- 原有共享 BlogContext、登录/密码访问限制和导航修复保留。
