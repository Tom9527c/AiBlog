# 追番页与追番数据改造设计

## 目标

让博客端追番页接近 Tom9527c.github.io-main 的列表视觉，并让后台能够维护番剧展示所需的统计数据。

## 数据设计

继续使用 `blog_bangumi.metadata` JSON，新增兼容字段：

- `state`: `wish`、`watching`、`finished`
- `progress`、`total`: 已看集数和总集数
- `rating`: 0 到 10
- `region`、`type`: 地区和番剧类型
- `plays`、`followers`、`coins`、`danmaku`: 播放、追番、硬币、弹幕统计

旧记录缺少字段时使用空值展示，不要求迁移旧数据。

## 接口

后端复用现有 bangumis 内容列表与保存接口，扩展 metadata 白名单和数值校验；公开列表继续遵守发布状态与访问策略，并返回允许公开的 metadata。

## 后台

追番表单增加统计与基本信息输入；追番列表增加封面、状态、进度和主要统计信息，复用现有内容管理器权限及保存流程。

## 博客端

追番列表保留“想看 / 在看 / 看过”筛选，单条内容采用封面、标题、状态进度、地区/类型、统计项、简介的横向布局，桌面端紧凑排列，移动端自动换行；空状态保持现有主题风格。

## 验证

增加 metadata 校验测试、后台表单类型检查和博客端追番卡片测试，并运行 Nest 类型检查、管理端类型检查、博客端测试与构建。
