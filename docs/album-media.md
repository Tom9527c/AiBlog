# 相册内容管理

后台入口：博客管理 → 相册管理 → 编辑相册 → 相册内容。相册正文与正文格式编辑器已移除，独立照片管理页面、路由和菜单已删除。已有相册/照片记录保留，原照片自动在所属相册显示。

新增相册先保存基本信息，抽屉保持打开，然后可批量选择 JPG、PNG、GIF、WebP、AVIF、MP4（单文件 25MB）。媒体上传继续使用统一存储配置。添加、改名、说明、排序、发布/草稿和移除即时保存，底部“保存相册”保存相册基本信息。排序数字越大越靠前。失败文件单独提示；已上传但未登记成功的文件可重试添加。

新媒体继承相册访问要求，原照片额外的登录/密码要求仍保留。管理员预览经媒体权限接口。移除相册项不会直接删除存储文件，可在文件管理中清理未引用文件。

博客端 GIF 按动图显示，视频卡片带视频标记，打开预览后提供原生播放器。支持瀑布流、网格和画廊布局。受保护相册解锁前不请求照片列表。

相册详情使用宽幅封面和紧凑图片墙，图片间距为 4px。瀑布流按图片实际比例组成等高行；网格保留固定比例，画廊保留单列。接近底部时自动追加下一页，加载失败可重试同一页，也保留手动加载入口。切换相册或登录状态后重置列表。

点击媒体打开深色全屏预览，可用方向键、左右按钮或触摸滑动切换，Esc 关闭并恢复焦点。图片支持缩放、拖动、缩略图、自动播放及浏览器全屏；图片说明用作预览说明，不显示文件名。预览组件按需加载，图片和视频继续通过原媒体权限接口读取。

升级旧环境，在 nest-admin 下运行 `node scripts/album-media-migrate.cjs`，只删除独立照片导航记录，保留照片数据和照片操作权限（移到相册菜单下）。最新博客初始化脚本不再创建独立照片页面。

相册 list 权限允许读取照片列表，update 权限允许增删改相册内容；原照片操作权限仍可用于 API。角色管理中按新的相册入口分配权限。
