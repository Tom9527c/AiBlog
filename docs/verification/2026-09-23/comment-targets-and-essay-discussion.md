# 评论对象与短文讨论

## 改动
- 后台评论对象显示文章标题／短文纯文本摘要（50 字）及短文日期，统一“即刻短文”名称；批量查询当前页关联对象。
- 对象链接打开对应内容的评论区；“只看此内容”按 targetKind + targetId 筛选，可关闭筛选标签。
- 短文列表批量返回公开评论数量，受限短文不暴露数量。评论计数过滤审核、发布时间、访问权限，以及不可见父评论下的回复。
- 瀑布流卡片默认折叠评论，一次展开一条；首次打开后保留组件状态，切换卡片保留主评论／回复草稿。
- 卡片紧凑模式加载 3 条主评论，各预览 1 条回复；查看全部讨论进入单条短文页。单条页宽版展示正文与完整分页评论，不再使用瀑布流列宽。
- 共享评论组件支持异步内容加载后的 #post-comment 定位；修正 compact 模式父组件重绘导致点赞状态回退的问题。
